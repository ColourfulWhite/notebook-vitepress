创建项目 ​

前置准备 ​

Node.js ​

项目地址：https://nodejs.org

Node.js 的版本要求使用 18 及以上。

使用 nvm 安装和管理 Node.js。

Linux ​

https://github.com/nvm-sh/nvm

  1. 获取安装脚本并执行

    sh
    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash

    这个脚本会克隆 nvm 的仓库到 ~/.nvm，并将环境变量加入到 ~/.bashrc 文件中。

  2. 使当前终端生效

    sh
    source ~/.bashrc

  3. 验证 nvm 安装

    sh
    command -v nvm

    如果 nvm 在当前终端生效，会输出 nvm：

    sh
    $ command -v nvm
nvm

    如果没有输出或输出 nvm: command not found，尝试打开一个新的终端后验证。

  4. 安装最新 LTS 版本的 Node.js

    sh
    nvm install --lts

  5. 验证 Node.js 安装

    sh
    node -v

    安装成功会输出 Node.js 的版本。

Windows ​

https://github.com/coreybutler/nvm-windows

  1. 获取程序

    在 https://github.com/coreybutler/nvm-windows/releases 下载最新版本的 nvm-setup.zip，解压后安装。

  2. 验证 nvm-windows 安装

    bat
    nvm -v

    安装成功会输出 nvm-windows 的版本。

  3. 安装最新 LTS 版本的 Node.js

    bat
    nvm install lts

  4. 使用最新 LTS 版本的 Node.js

    bat
    nvm use lts

  5. 验证 Node.js 安装

    bat
    node -v

    安装成功会输出 Node.js 的版本。

pnpm ​

使用 pnpm 作为包管理器：

sh
corepack enable pnpm

安装 VitePress ​

进入到需要安装 VitePress 的目录，使用 @next 安装最新版本的 VitePress：

sh
pnpm add -D vitepress@next

创建项目 ​

安装完成后，运行 VitePress 的安装向导创建一个 VitePress 项目：

sh
pnpm vitepress init

使用 src 目录作为项目根目录和源目录，并使用 docs 作为脚本的前缀。

启动服务 ​

使用 docs:dev 启动具有即时热更新的本地开发服务器：

sh
pnpm run docs:dev

服务默认启动在 5173 端口，使用 http://localhost:5173/ 访问。
